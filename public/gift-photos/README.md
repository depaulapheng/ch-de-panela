# Photographs of the reviewed gift catalogue

These are cached copies of individually reviewed, publicly licensed source photographs.
The complete per-file author, source, license, dimensions and SHA-256 attribution ledger is
[`lib/verified-gift-photos.json`](../../lib/verified-gift-photos.json).
Photographic source bytes are unchanged; CSS uses `object-fit: contain`, not a destructive crop.
Photographs are illustrative, not a requirement to purchase a particular brand or model.

Each card links to its author/source and applicable license. Share-alike/public-domain terms
remain applicable to each photograph separately; bundling does not relicense source images.

- [Creative Commons BY 2.0](https://creativecommons.org/licenses/by/2.0/)
- [Creative Commons BY-SA 2.0](https://creativecommons.org/licenses/by-sa/2.0/)
- [Creative Commons BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/)
- [Creative Commons BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)
- [Creative Commons CC0](https://creativecommons.org/publicdomain/zero/1.0/)
- [Pexels License](https://www.pexels.com/license/)

Only exact reviewed source URLs use these bundled snapshots. A later image selected in
the administration panel continues through the existing image/proxy workflow.
